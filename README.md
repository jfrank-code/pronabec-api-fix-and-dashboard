# pronabec-api-fix-and-dashboard
Dashboard interactivo en Excel con datos de PRONABEC. Ante fallos en la API oficial, se realizó un diagnóstico técnico con Python para identificar los controladores internos del backend. Con las rutas corregidas, se usó Power Query para extraer 87,576 registros y diseñar el cuadro de mando optimizado para la web.
